Terminal state in deptty is accessed only via `shared.term.lock()` — a `FairMutex`. `Shared` holds the `FairMutex<Term<TitleListener>>` plus the pty writer. The reader thread holds the lock across `Processor::advance(term)`; the GUI thread locks briefly per paint — keep GUI-side lock scopes tiny. Never touch the term from GUI code without the lock; all dtk widget calls stay outside the lock scope (consistent with the no-RefCell-borrow-across-dtk-calls rule). Tab close = `SIGHUP` to the shell pid; UI removal happens on the reader thread's EOF poke (`'q'`) — don't remove tabs directly, keep one code path for "shell gone". Scrollbar sync has a re-entry guard (`syncing` Cell) — keep it.
