dtk-rs master (commit 1b93f97a, Oct 2026) breaking changes vs d7a55c62:
- QColor/QPoint(F)/QSize(F)/QRect(F)/QMargins(F)/QUrl are now cxx-qt-lib by-value types (cxx-qt-lib 0.10). QColor constructors renamed: `QColor::rgb(r,g,b)` -> `QColor::from_rgb(r,g,b)` (3 args), `QColor::rgba(r,g,b,a)` -> `QColor::from_rgba(r,g,b,a)` (4 args). Heap wrapper deleters gone.
- Generated typed signals (dtk/src/signals_gen.rs, 300 signals / 77 classes): `on_*` methods return RAII `Connection` — **dropping it disconnects the signal**; call `.release()` (returns usize id) for app-lifetime connections. deptty's repaint timer broke this way (silent: compiles with only a must_use warning).
- Old string-based `connect_signal*` trait methods (dtk/src/lib.rs) still exist and return plain usize — no must_use, drop-safe. Mixed old/new API in one codebase compiles fine.
- New typed DTabBar signals: `on_current_changed(i32)`, `on_tab_close_requested(i32)`, `on_tab_moved(i32,i32)`, `on_tab_add_requested()`.
deptty adaptation commit: 528b288 on github st0nie/deptty main.
